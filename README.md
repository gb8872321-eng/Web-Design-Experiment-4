# Web Design Experiment 4

Optimizing a webpage for SEO and accessibility using semantic HTML, a proper heading structure and meta tags.

## What was done
- Semantic tags: header, nav, main, article, section, aside, footer
- Only one h1 and h2 headings for sections
- Meta tags: title, description, keywords, author, robots, Open Graph
- Image has alt text, width and height
- Form input has a label
- Skip link, focus styles and good colour contrast for accessibility

## Files
- index.html - optimized web page
- style.css - styling
- images/healthy-living.png - image used in the page
